# Literature

This directory used to hold full copies of the two papers below (arXiv HTML and LaTeX sources). They were
removed before the first archived release because they belong to their authors and are not covered by this
repository's licenses. Please read and cite the originals:

- Yuzhou Gu and Mark Sellke, *A Counterexample to the Gaussian Completely Monotone Conjecture*,
  [arXiv:2605.11656](https://arxiv.org/abs/2605.11656).
- Jiayang Zou, Luyao Fan, Jiayang Gao and Jia Wang, *An Explicit Family of Log-Concave Counterexamples to the
  Gaussian Completely Monotone Conjecture*, [arXiv:2608.30275](https://arxiv.org/abs/2608.30275).

`download_manifest.json` and `retrieval.json` are the original retrieval logs (URLs, sizes, status) kept as a
record; the file paths they list no longer exist in the repository. The conventions and the claims checked
against these papers are recorded in [`../notes_literature.md`](../notes_literature.md).
